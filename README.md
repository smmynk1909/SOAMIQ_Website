# SOAMIQ LABS Website

A lightweight, dependency-free website for SOAMIQ LABS. The site is built with plain HTML, CSS, and JavaScript so it can be opened locally, hosted on any static host, or used as the foundation for a future framework-based build.

## Files

- `index.html` - page structure, copy, SEO metadata, and contact form
- `styles.css` - responsive visual design and layout
- `script.js` - mobile navigation, scroll states, reveal animations, and form validation

## Run locally

Open `index.html` directly in a browser, or serve the folder locally:

```bash
python3 -m http.server 4173
```

Then visit `http://localhost:4173`.
